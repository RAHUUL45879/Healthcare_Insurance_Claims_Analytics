# Healthcare Insurance Claims Analytics — Excel Dashboard Report

## 🔹 Project Overview
This project delivers a production-grade healthcare insurance claims analytics solution built using Python for data processing and Excel for executive dashboards.
It converts large, raw insurance claim datasets into actionable financial and operational insights across multiple years, insurers, and providers.

  ## 🔹 What This Project Solves
  
• Tracks Claimed, Received, Denied, and Pending amounts

• Identifies revenue leakage & delayed payments

• Measures rejection ratios by year, payer, and doctor

• Enables monthly, yearly, and multi-dimensional analysis
